# Outputs by trail

One folder per Pilegrimsleden trail. Folder names map ae/o/a from
Norwegian special letters and drop the dot in St. Olavsleden for
filesystem safety.

Open `trail.osm` in JOSM (the only `.osm` file per folder). It includes the
path, CMS overnight POIs, and **existing OSM lodging to add to the live route
relation** (`role=route_add`). Search: `note:relation_member=Add as member of
OSM route relation`. Uploading new CMS suggestion nodes as written does not
rewrite membership of existing OSM route relations.

Romeriksleden is Gudbrandsdalsleden east (Oslo–Eidsvoll–Hamar–Lillehammer),
mapped in OSM as relation 1200009 but not a separate pilegrimsleden.no trail
entry.
