# Outputs by trail

One folder per Pilegrimsleden trail. Folder names map ae/o/a from
Norwegian special letters and drop the dot in St. Olavsleden for
filesystem safety.

Open `trail.osm` in JOSM (the only `.osm` file per folder). It is a local
research `type=site` file (one densified path + lodging), not a dump of the
live OSM route relation’s hundreds of way members. Uploading it as written
adds new objects only and does not rewrite membership of existing OSM route
relations.

Romeriksleden is Gudbrandsdalsleden east (Oslo–Eidsvoll–Hamar–Lillehammer),
mapped in OSM as relation 1200009 but not a separate pilegrimsleden.no trail
entry.
